民藏平台 · 前端细化体验版
更新日期：2026-10-28

一、先打开哪里
解压整个文件夹后，双击 index.html 即可体验，不需要启动 SQL Server。
请保持 assets 文件夹与 index.html 在同一目录，不能只发送单个 HTML 文件。
右上角“切换体验”可以切换普通用户、专家、机构、管理员和超级管理员。
若浏览器限制本地存储，操作可能不能跨关闭保留。

二、这次做了什么
1. 将原来通用的发布弹窗细化为藏品、帖子、问题、话题、课程、活动、专题展览和公告表单。
2. 增加内容详情、搜索筛选、点赞、收藏夹、评论、回复、问答与采纳、关注拉黑、私信和通知。
3. 增加身份申请与审核、专家邀请、机构单独申请课程发布资格。
4. 增加视频课时编辑与播放入口、课程评分、活动报名审核和演示证书。
5. 增加藏品鉴定任务分配、专家意见、补充材料、最终审核，以及角色权限、举报和申诉流程。
6. 操作记录保存在本机浏览器；刷新不会主动恢复初始样例。顶部“重置演示”会清空本版本的演示操作。

三、建议按这个顺序检查
1. 用林知秋体验资源库、论坛、提问、收藏夹、私信、藏品草稿及提交。
2. 在个人中心申请课程发布人；切换陈宁到管理后台审核；再切回来查看身份与通知。
3. 切换江南民俗文化中心：可以管理活动，起初没有发布课程资格。申请并通过后再检查课程入口。
4. 用许文博查看课程编辑与专家工作台。
5. 用管理员在“鉴定任务与最终审核”中分配适配领域的专家；分别切换专家提交意见，再进行最终审核。
6. 用周明管理角色与权限，再切换其他管理员体验权限限制。

四、当前边界（请务必阅读）
这是一份前端交互演示，不是已经完成的全栈系统。
它不读取、修改你的 SQL Server，不会影响已经建好的49张表和假数据。
页面使用少量虚构样例，并非数据库导出的假数据。
账号切换不是真实登录，权限判断仅用于演示；实际安全校验必须在后端实现。
视频、资质、图片与材料目前使用地址或本地预览，没有文件上传服务。
不含课程视频；选本地视频可以体验播放器，但不会上传。
个人资料审核、部分字段编辑、分类层级与专题排序等尚需进一步细化，详见《功能与49张表对照.md》。
字段对照.json 从最新报告49张表抽取，供核对；不是已完成数据库映射的证明。

五、关于 ASP.NET 项目
Default.aspx 与 index.html 使用同一套细化版页面。
原有解决方案、Web.config 和 DatabaseTest 页面保留；DatabaseTest 只是原有连接测试页面，并未接入业务。
只看网页无需打开这些文件；后续接后端时再配置实际服务器与数据库。
本次没有连接数据库，也没有执行任何 SQL。

六、验证情况
通过 JavaScript 语法检查。
通过28个页面路径的模拟渲染检查，以及身份审核、报名审核、收藏点赞、评论回答、三专家鉴定、权限拒绝的模拟状态检查。
模拟检查不能替代真实浏览器测试。当前环境无法完成实际浏览器布局与点击验证，尚不能承诺所有浏览器上的显示和交互完全正确。

七、保存方式
D盘原项目未被覆盖。本文件夹是独立的细化版本。
请先保存旧版，再逐项体验新版；可记录具体页面和操作步骤，继续修正。
